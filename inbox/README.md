# Inbox Contract

ChatGPT writes only two kinds of Markdown files here:

- `SPEAKING_CASE_UPDATE`: a confirmed case created after the user says `保存案例`.
- `REVIEW_UPDATE`: a progress update created after the user says `完成复习`.

Use the templates in `templates/`. Do not write generated indexes, website files, or review lists here. The GitHub Action processes each inbox update automatically.
