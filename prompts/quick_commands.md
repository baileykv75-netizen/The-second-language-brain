# Quick Commands

Use these messages inside the ChatGPT Project after the long-term instructions are installed.

## Start Article Study

```text
开始文章学习

Source URL: <link>
Source title: <title>
Short excerpt: <a short permitted excerpt>
My summary: <what I think the article says>
My first reaction: <my opinion or question>
```

## Save A Case

```text
保存案例
```

## Start Today's Review

Copy a task from the GitHub Pages website and paste it into the Project chat.

## Complete A Review

```text
完成复习
```
